#Creative-Portfolio-Landing-Page 🎨

A modern animated landing page built using **HTML5** and **CSS3**, inspired by contemporary portfolio and design showcase websites. This project focuses on smooth animations, interactive hover effects, and a clean, responsive user interface.

---

## 🌐 Live Demo

🔗 [Creative-Portfolio-Landing-Page.](https://kanika01-ux.github.io/Creative-Portfolio-Landing-Page/)

## 🚀 Features

- ✨ Smooth infinite scrolling logo marque
- 🎨 Modern and minimal UI design
- 📱 Responsive layout
- 💫 CSS transitions and animation.
- 🖼️ Image and video cards

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Animations
- CSS Transitions
